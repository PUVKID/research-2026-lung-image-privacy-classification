# 🧹 1차 공개 자료 정리

저자·공동저자와 학교·이메일·사진은 유지하면서 학과·학부 세부 표기를 제외한 논문 PDF를 정리했습니다. 편집 원문은 로컬에 보존하고 검수된 PDF로 연결합니다.

개발 차수 사이의 기능·설정·주석·공백 차이는 기존 상세와 전체 비교에서 확인할 수 있습니다. 이번 개인정보 삭제 구간은 원문 값을 패치에 다시 적지 않고, 실제 파일 경로·변경 유형·크기·SHA-256으로 기록합니다.
